# Unity 프리팹 썸네일 생성기

Unity 에디터에서 프리팹을 일정한 크기로 조정하여 썸네일 아이콘을 자동으로 생성하는 도구입니다.

## 📌 주요 기능

### 기본 버전 (`PrefabThumbnailGenerator.cs`)
- ✅ 자동 크기 조정 (최대 2 유니티 단위, 최소 1x1)
- ✅ 마젠타 배경 투명화
- ✅ PNG 포맷 저장
- ✅ 일괄 처리

### 고급 버전 (`PrefabThumbnailGeneratorAdvanced.cs`)
- ✅ **실시간 미리보기** - 결과를 미리 확인
- ✅ **3점 조명 시스템** - 전문가급 렌더링
- ✅ **안티앨리어싱** - 깨끗한 경계선
- ✅ **취소 기능** - 대량 처리 중 중단 가능
- ✅ **스마트 스케일링** - 3가지 모드 (Uniform, PerAxis, FitToSquare)
- ✅ **설정 프리셋** - 아이템/건물/캐릭터
- ✅ **정렬 옵션** - 중앙/바닥 기준

## 🚀 설치 방법

1. Unity 프로젝트 폴더에 다음 파일들을 복사:
   ```
   Assets/
   └── Editor/
       ├── PrefabThumbnailGenerator.cs (기본 버전)
       └── PrefabThumbnailGeneratorAdvanced.cs (고급 버전)
   ```

2. Unity 에디터에서 자동으로 스크립트가 컴파일됩니다.

## 📖 사용 방법

### 1. 에디터 툴 열기

**기본 버전:**
- Unity 메뉴: `Tools > Prefab Thumbnail Generator`

**고급 버전:**
- Unity 메뉴: `Tools > Prefab Thumbnail Generator (Advanced)`

### 2. 기본 설정

#### 타겟 Prop 지정
- **중요!** 씬에 빈 GameObject를 만들고 이것을 "타겟 Prop"으로 지정하세요.
- 프리팹들이 이 오브젝트의 자식으로 임시 배치되어 썸네일이 생성됩니다.

#### 출력 설정
- **출력 폴더**: 생성된 PNG 파일이 저장될 위치 (기본: `Assets/GeneratedIcons`)
- **해상도**: 128 ~ 2048px (기본: 512px)

#### 크기 조정 설정
- **최대 크기**: 오브젝트가 넘지 않을 최대 유니티 단위 (기본: 2.0)
- **최소 크기**: 너무 작은 오브젝트를 키울 최소 크기 (기본: 1.0)

### 3. 프리팹 추가

**방법 1: 수동 추가**
1. "프리팹 추가" 버튼 클릭
2. Project 창에서 프리팹 드래그 앤 드롭

**방법 2: 일괄 추가**
1. Project 창에서 여러 프리팹 선택
2. "선택 일괄 추가" 버튼 클릭

### 4. 썸네일 생성

**기본 버전:**
1. "썸네일 생성" 버튼 클릭
2. 진행 상황 확인
3. 완료 후 `Assets/GeneratedIcons` 폴더 확인

**고급 버전:**
1. **미리보기 탭**에서 결과 미리 확인 (권장)
2. 설정이 만족스러우면 "썸네일 생성" 클릭
3. 필요시 중간에 "취소" 가능

## 🎨 고급 기능 (Advanced 버전)

### 미리보기

1. "미리보기" 탭 선택
2. 프리팹 선택
3. "미리보기 생성" 클릭
4. 설정 변경 후 "미리보기 갱신"으로 즉시 확인

### 스케일 모드

| 모드 | 설명 | 추천 용도 |
|------|------|-----------|
| **Uniform** | 모든 축 동일 비율 스케일 | 일반 아이템, 비율 유지 필요 |
| **PerAxis** | 각 축별로 독립적 스케일 | 극단적 비율 오브젝트 |
| **FitToSquare** | XZ 평면 기준 정사각형 맞춤 | 건물, 지형 |

### 정렬 옵션

- **Center**: 오브젝트 중심 기준 (기본)
- **Bottom**: 바닥 기준 정렬 (건물, 캐릭터에 적합)

### 조명 설정

고급 버전은 **3점 조명 시스템**을 사용합니다:

- **Main Light**: 주 광원 (45도 각도)
- **Fill Light**: 보조 광원 (그림자 완화, 푸른빛)
- **Rim Light**: 테두리 강조 (따뜻한 빛)

옵션:
- `조명 활성화`: 3점 조명 사용 여부
- `그림자 활성화`: 그림자 렌더링 (성능 영향 있음)

### 프리셋

빠른 설정을 위한 3가지 프리셋 제공:

#### 아이템 아이콘
```
해상도: 256px
카메라 각도: (15°, -30°, 0°)
정렬: 중앙
그림자: 꺼짐
```
→ 인벤토리 아이템, 소품에 적합

#### 건물 썸네일
```
해상도: 512px
카메라 각도: (30°, -45°, 0°) - 아이소메트릭
정렬: 바닥 기준
그림자: 켜짐
```
→ RTS, 시뮬레이션 게임 건물

#### 캐릭터
```
해상도: 512px
카메라 각도: (10°, 0°, 0°) - 약간 위에서
정렬: 바닥 기준
최소 크기: 1.5 (크게 표시)
```
→ 캐릭터 초상화, 유닛 아이콘

## 🎯 워크플로우 예시

### 예시 1: 인벤토리 아이템 100개

1. 씬에 빈 GameObject 생성 → "IconProp"으로 이름 변경
2. 고급 버전 툴 열기
3. "아이템 아이콘" 프리셋 클릭
4. Project에서 아이템 프리팹 100개 선택
5. "선택 일괄 추가" 클릭
6. "미리보기" 탭에서 몇 개 확인
7. "썸네일 생성" 클릭
8. ☕ 커피 한 잔 (대략 1-2분 소요)

### 예시 2: 건물 썸네일 커스터마이징

1. 씬에 빈 GameObject 생성
2. 고급 버전 툴 열기
3. "건물 썸네일" 프리셋 적용
4. 고급 설정 탭:
   - 카메라 각도 조정 (예: 35°, -40°, 0°)
   - 그림자 켜기
   - 해상도 512px로 설정
5. 프리팹 하나 추가
6. "미리보기" 탭에서 결과 확인
7. 설정 만족하면 나머지 프리팹 추가
8. "썸네일 생성"

## ⚙️ 설정 가이드

### 카메라 거리
- 너무 가까움: 오브젝트가 잘림
- 너무 멀음: 오브젝트가 작게 보임
- **권장**: 5 ~ 7

### 카메라 각도
- **(0, 0, 0)**: 정면
- **(15, -30, 0)**: 아이템 아이콘 (기본)
- **(30, -45, 0)**: 아이소메트릭 (RTS)
- **(90, 0, 0)**: 위에서 (탑다운)

### 해상도
- **128px**: 작은 UI 아이콘
- **256px**: 인벤토리 아이템
- **512px**: 상점, 카탈로그 (권장)
- **1024px+**: 고품질 홍보 이미지

## 🔧 문제 해결

### Q: 썸네일이 너무 작게 나와요
**A:** "최소 크기" 값을 늘려보세요 (예: 1.5 또는 2.0)

### Q: 오브젝트가 화면에서 잘려요
**A:**
- "최대 크기" 값을 줄이거나
- "카메라 거리"를 늘리세요

### Q: 배경이 완전히 투명하지 않아요
**A:**
- 배경색이 정확히 마젠타(#FF00FF)인지 확인
- 고급 설정에서 `backgroundColor` 값 조정
- 코드의 `threshold` 값을 0.15로 증가

### Q: 프리팹에 Renderer가 없다고 나와요
**A:**
- 프리팹이 빈 오브젝트인지 확인
- MeshRenderer나 SkinnedMeshRenderer가 있는지 확인
- Collider만 있는 경우 메시를 추가해야 함

### Q: 조명이 너무 밝거나 어두워요
**A:**
코드에서 조명 intensity 조정:
```csharp
mainLight.intensity = 1.0f;  // 0.5 ~ 1.5
fillLight.intensity = 0.4f;  // 0.2 ~ 0.6
rimLight.intensity = 0.6f;   // 0.3 ~ 0.8
```

### Q: 대량 처리가 너무 느려요
**A:**
- 해상도를 낮추세요 (512 → 256)
- 안티앨리어싱 끄기
- 조명/그림자 끄기
